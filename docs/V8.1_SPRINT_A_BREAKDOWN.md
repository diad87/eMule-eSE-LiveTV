## 1. Wire format nuevo — fragmentación multi-cell

La sub-cabecera de 7 B **no cambia**. Para ops v8.1 (`sub_cmd ≥ 0x40`), el `body` empieza con una **cabecera de fragmento de 8 B**:

```
Plaintext tras onion-peel de una celda v8.1:
  [0]      sub_cmd        uint8        (≥ 0x40)
  [1..4]   req_id         uint32 LE    (= id de mensaje; correla request↔reply)
  [5..6]   text_len       uint16 LE    (= 8 + len(frag_data) en ESTA celda)
  [7..8]   frag_index     uint16 LE    (0-based)
  [9..10]  frag_count     uint16 LE    (nº total de fragmentos; 1 = mensaje de 1 celda)
  [11..14] msg_total      uint32 LE    (bytes del mensaje completo reensamblado)
  [15..N]  frag_data      bytes
```

**Regla de compatibilidad:** `sub_cmd < 0x40` ⇒ legacy single-cell (body crudo, como hoy). `sub_cmd ≥ 0x40` ⇒ siempre lleva la cabecera de 8 B. Un peer v8.0.0 no conoce ningún op ≥0x40 y, por A7, nunca los recibe.

**Presupuesto por celda (2 hops):** 505 − 32 (2 tags AEAD) − 7 (sub-hdr) − 8 (frag-hdr) = **458 B de `frag_data`/celda**. Un mensaje de M bytes ⇒ `ceil(M/458)` celdas.

### Constantes nuevas (`LiveCellQueue.h` o `LiveTunnel.h`)

TUN_FRAG_DATA_MAX_2HOP    = 458         // informativo; recalcular si nº de hops cambia

## 4. Gotchas

- **No** cambiar la celda de 512 B ni la sub-cabecera de 7 B — la fragmentación va en el body (compat v8.0.0).
- El exit guarda estado (reassembly + `ExitOperation`) ⇒ superficie de DoS. Los límites A1.6 y el sweeper A5 son **obligatorios**.
- `OnionDecryptAll` escribe en `plain[CELL_PAYLOAD_MAX]` (505). El presupuesto de 458 B/celda es para 2 hops; recalcular si el circuito tiene otro nº de hops.
- Evento Win32 cross-thread: liberar el `PendingRequest` en el lado del waiter, nunca en el del señalizador (race de use-after-free).
- No meter `m_reassembly`/`m_pending` bajo `m_lock` (circuitos) — usar `m_pendingLock` o uno dedicado, para no serializar el envío de celdas.
- Los 3 maps actuales (`m_pendingPingReplies`/`KadResults`/`BuildResults`) se **sustituyen** por `m_pending` (A3.1) — no dejar los viejos colgando.
