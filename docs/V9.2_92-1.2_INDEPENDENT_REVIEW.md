- Variable public identifiers are domain-separated SHA-256 digests.
- Event, outcome, reason, verdict, state and allocation labels use closed v1
  vocabularies.
- Unknown hostile property names are represented as `*` in errors.
- Root and nested Proxies are rejected before traps execute.
- Dense-array validation rejects empty and partially sparse arrays.
- Non-empty owner proofs are bound to their protocol in loader, model,
  renew/delete operations and report projection.
- `none` remains representable but never authorizes renewal or deletion.
- Initial mappings must match the gateway initial epoch and generation.
- Public owner projection validates complete UPnP, PCP and NAT-PMP shapes and
  exports only domain-separated digests, never nonce, scope, description or
  gateway identity material.

## Residual risk

Deterministic digests intentionally allow correlation and may permit
enumeration of very low-entropy logical identifiers. This is a known property
of the current domain-separated SHA-256 contract and is not blocking for
`92-1.2`; callers must continue to use non-secret logical identifiers.
