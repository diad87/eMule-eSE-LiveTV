# V9.2 K03 — Auditoría de puertos locales y anunciados

## Alcance

Auditoría cerrada sobre `srchybrid` desde el commit base `1cfe867b`.
Se revisaron las 110 referencias encontradas a los getters propios de puerto:

- `thePrefs.GetPort()` y `thePrefs.GetUDPPort()`;
- aliases locales `GetLocalTcpPort()` y `GetLocalUdpPort()`;
- getters `GetAdvertised*Port()` IPv4 e IPv6;
- la frontera `CDirectReachabilityManager` → `CemuleApp`.

Cada referencia se clasificó por su efecto, no por el nombre del método
contenedor.

## Reglas congeladas

| Clase | Getter autorizado | Ejemplos |
|---|---|---|
| bind/local | preferencia o `GetLocal*Port()` | listeners TCP/UDP, firewall, mapper, relay local |
| advertised/external | `theApp.GetAdvertised*Port()` | hello, login, enlaces, publish, Live, Web/API |
| UI local | preferencia local | configuración y diagnóstico de listeners |
| UI pública | `GetAdvertised*Port()` | endpoint público y prueba externa |
| Kad interno | `CPrefs::GetInternKadPort()` | bind, firewall test y tags que distinguen interno/externo |
| remoto | getter del objeto remoto | servidor, contacto, buddy o cliente; fuera de sustitución |

No se hizo una sustitución global de `GetPort()`/`GetUDPPort()`: esos nombres
también pertenecen a servidores, contactos y clientes remotos.

Con mappings desactivados, los getters anunciados conservan compatibilidad:
devuelven los puertos locales. Con un mapper que conceda puertos distintos,
los consumidores anteriores ya no publican ni comparan el valor local.

## Casos revisados y preservados

- `ListenSocket`, `ClientUDPSocket`, firewall, wizard y `StartDiscovery` usan
  puertos locales porque abren o solicitan recursos del host.
- `CPrefs::GetInternKadPort()` sigue siendo local para bind y firewall test.
  Las rutas que serializan endpoints externos consultan ahora la autoridad
  común `GetAdvertisedUdpPort()`; no se cambió el contrato del getter interno.
- Los consumidores wire ya migrados (`BaseClient`, `ServerConnect`,
  `KademliaUDPListener`, `Search`, Live, Web/API y enlaces) usan getters
  anunciados.
- `PartFile.utf8.cpp` sigue siendo una copia histórica versionada pero no
  incluida en `emule.vcxproj`; no es un call site de producción. W12 retiró
  `WebServer_original.cpp`, la copia obsoleta del servidor web, para dejar
  una única implementación y eliminar la exclusión especial del inventario.
