# V9.2 L04 — checkpoint AI-F08

Estado: checkpoint aprobado por revisión Sol/high independiente.

## C-BASELINE

La base `7c0a5ab2` usaba los nombres globales `eMule_TCP_Port` y
`eMule_UDP_Port` para todas las instancias. El alta moderna retiraba primero
una regla con el mismo nombre. Dos perfiles podían por tanto colisionar o
retirar una regla ajena aunque los ownership gates de UPnP, PCP y NAT-PMP
fueran correctos.

La selección automática de puertos locales usaba `GetRandomUInt16()`, cuya
implementación histórica no constituye una fuente de entropía del sistema.

## C-RED

Los contratos L04 exigen que la ruta productiva:

1. crear un namespace aleatorio, no sensible y estable por perfil;
2. scopee toda alta, consulta y retirada por nombre antes de cualquier backend;
3. rechace una prueba incompleta o extranjera;
4. no acepte una alternativa aleatoria sin entropía del sistema.

La base no contiene `BuildOwnedRuleInfo`,
`LoadOrCreateFirewallOwnerToken`, `BuildOwnedFirewallRuleName` ni
`GetUniformSystemRandomPort`; por tanto no satisface esos contratos.
