## Regla de cierre

`PASS` requiere implementación, prueba unitaria, integración aplicable y
evidencia del mismo commit. `PARTIAL`, `BLOCKED` y `PLANNED` nunca se agregan
como éxito.

## Evidencia incremental 92-3.6 / L07

- `V92-F02`, `V92-F04` y `V92-F08`: corpus hostil de 2.245 checks con
  tamaños PCP exhaustivos `0..1101`, reserved fields compatibles con RFC
  6887, lifetime extremo limitado a 24 h, epoch wrap, nonce/gateway/address
  incorrectos, respuesta duplicada y replay generacional.
- Integración: `tests/test_v92_l07_hostile_corpus.py` 6/6 y WP0 296
  (295 PASS + 1 skip esperado), sin privilegios ni mutación física.
- Regresión: `libnatmap` completo PASS, state 182.840/182.840,
  estabilidad 1.122.500/1.122.500 y Release x64 PASS.
- Revisión independiente: PASS; 0 S0, 0 S1, 0 S2 y 0 S3 abiertos.

## Evidencia incremental 92-3.7 / L08

- WebServer privado por defecto: escucha en `127.0.0.1` cuando no existe una
  dirección explícita de enlace y la preferencia heredada `WebUseUPnP` se
  ignora, se guarda como `false` y no puede reactivarse desde la interfaz.
- Cero exposición automática: la entrada inicial, la activación tardía y los
  cuatro backends (MiniUPnP, PCP, NAT-PMP y servicio UPnP de Windows) fuerzan
  el puerto Web a cero, conservando únicamente la retirada de reglas antiguas.
- Privacidad de evidencia: owner, nonce, IP y gateway pasan por digest o
  sanitización central; el paquete exige `WebUseUPnP=0` y verifica el contenido
  exacto del ZIP contra su manifiesto.
- Integración: contrato host 7/7; runtime 2/2 para proyección canónica,
  informe JSON/Markdown real, ZIP positivo, ZIP alterado rechazado y grafo de
  cuatro scripts no interactivo/no privilegiado; WP0 296 (295 PASS + 1 skip
  esperado) y regresión eSE 35/35.
- Regresión: estabilidad final host 1.750/1.750 y 20/20 ciclos runtime
  (120 controles), herramientas de laboratorio PASS, preflight de release
  PASS y Release x64 PASS.
- Revisión independiente Sol/high: PASS final; dos S2 y un S3 corregidos
  durante los ciclos de revisión; 0 S0, 0 S1, 0 S2 y 0 S3 abiertos.

## Evidencia incremental 92-4.1 / M01

- Política pura IPv4/IPv6 con clases y razones estables; la publicación IPv6
  usa una lista positiva fail-closed de los bloques globales asignados por
  IANA a 2025-10-10 y rechaza espacio reservado, 6to4 y documentación.
- Origen de red independiente `NATIVE`/`OVERLAY`/`UNKNOWN`; Tailscale, WARP,
  WireGuard, ZeroTier y equivalentes conocidos quedan como overlay, y una

  incluidos `/32`, `/128` y prefijos no alineados a byte; RFC6598 nunca entra.
