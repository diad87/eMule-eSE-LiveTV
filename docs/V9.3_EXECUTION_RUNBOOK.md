## 24. Diagnóstico

### Baseline falla

Guardar primer fallo/toolchain, reproducir sin editar, comparar commit, marcar
`BLOCKED` y no cambiar el número esperado.

### uTP conecta pero no hay sesión

Comprobar intento/generación, expectation, Hello, SecureIdent, peer, nominación
y primer bloque. No promover lo provisional.

### Doble conexión

Congelar timelines/tie-break/IDs, activar `ESC-DOUBLE` y entregar a Sol. No
añadir sleeps.

### Punch3 no avanza

Comprobar reserva, expiry, servicio, generación, endpoint B, return proof,
half-RTT y cuotas. No usar R como proxy.

### Más de 17 destinos

- predicción: S1;
- Birthday: verificar engine, K/B/rate y una IP;
- counters/expectations compartidos: S1 y `ESC-BIRTHDAY`.

### DVL no migra

Comprobar transcript, link ID, generación, challenge/response, replay window y
path anterior. No aceptar endpoint por recibir datos.

### Tasa inestable

Congelar cohorte, denominador, seed, versión y celdas; activar `ESC-STATS`.
