## Estados permitidos

Estados de programa:

```text
BLOCKED_BY_SPEC_RECONCILIATION
READY
RUNNING
BLOCKED
RELEASED
```

Estados de tarjeta:

```text
NOT_STARTED
READY
IN_PROGRESS
VERIFYING
REVIEW
BLOCKED
DONE
WAIVED
NOT_APPLICABLE
```

Solo una tarjeta puede estar `IN_PROGRESS`. `WAIVED` requiere decisión humana,
caducidad y prueba compensatoria. S0/S1 no puede cerrarse como `WAIVED` sin
aceptación explícita.

`NOT_APPLICABLE` satisface una dependencia únicamente cuando una rama
condicional se cerró por decisión prevista —por ejemplo,
`NETLAB_STOP→NETLAB_ONLY`— y la evidencia de esa decisión está enlazada.
